**动作：** 每步输出 4 维机体位移 `(dx, dy, dz, dyaw)`（米|弧度 / 步），不是独立速度维。`step_hz=5` 时执行速度 = 位移 / `dt`（`max_dx=2.0` → 约 10 m/s）。训练与部署必须同一频率。当前机体速度走观测里的 `body_vel`，不占动作维。

## 回路

1. 当前 RGB、位姿、速度进入世界模型，收成隐状态。
2. 训练世界模型时，`depth_decoder` 迫使这份隐状态能解出空间深度。想象打分不读取这张图。
3. 对每个候选，在隐空间里向前滚 H 步。部署时 H=15，与训练一致。闭环时第一步是候选动作，其后各步由 Actor 在想象里自己出动作。
4. 每步奖励 = 朝目标直飞（大权重）+ 靠近目标的进度（`w_progress=1`）− 机动代价 − 障碍代价 − 不动 − 远离目标 − 一直平飞。障碍代价由隐状态和这一步动作预测。一条未来的得分是这些步的和（`roll.returns`）。
5. 取得分最高的未来，执行它的第一步。

真实一步和想象用同一套奖励。障碍代价两边都用完整隐状态加动作的预测，不读罩的画面深度。直飞、不动、远离目标、一直平飞两边都用机体动作和**当前栈写入的**机体目标方向（toward_g 下是 carrot / `goal_rel`，不是终端 G 的世界坐标；与 Actor、想象一致）。

**障碍代价刻度：** 新头的输出直接作为每步障碍代价（或经固定仿射）。`reward_terms` 里不再用「旧 clearance 崖 × `w_collision=10`」。若仍走 `w_collision * risk` 形状，则任务 3 写死常数时把 `w_collision` 设为 1（或并入常数），避免 10× 把刻度又拉回盖过直飞。硬碰撞：`obs.collided` 时该步障碍代价取本步上界（不低于任务 3「前方很近」常数）。

**罩（三区速度盾）：** 用 S-8j 画面深度改真实执行速度；想象里没有罩。本轮**策略训练采集关罩**（`--no-shield`），逼 Actor 自己学会绕障；`w_intervention` 在关罩时为 0，碰撞仍靠真值 `collided` 与障碍代价。**部署 / 验收再开罩**作安全网。主张「模型会了」时，至少有一组罩关数字；罩开到达不得单独过关。本轮不换官方 DA3，不拟合全局倍数 `a`。罩的输出不进入奖励。

## 现在为什么会选错

障碍代价来自画面中心的一个距离，乘 `w_collision=10`。≤3 m 记成 1，≥22 m 记成 0。侧移、上飞、直行扣同一份分。8 m 大约罚 7.4，每米进度只加 1。旧代码再把「这一帧已经撞上」的二元分数和这个距离取最大值。太近、擦边不在那个二元标签里，换动作它也不变。

左边有墙、正前方是路时，往左和往前的障碍扣分相同。空旷方向扣分接近 0，所以往空处退、停住、或一直平飞，都可能比朝目标走进街巷得分更高。

真实一步的奖励现在读的是罩的前向锥（`depth_min_pred` / `depth_cones_pred`），和想象用的中心距离不是同一个量。两路都与动作方向无关。

v16（`closed_loop`，H=15，手写偏置关）四条全撞，最近距离约 40–63 m。闭环口已经在。缺的是回报，不是再加一条规划规则。

## 决定

1. **停掉 `rl_learn`。** 按 PID 停。PID 变了就按日志路径认进程。不用会误伤 ssh 的 `pkill -f`。
2. **几何留在隐状态里。** `depth_decoder` 只在训练世界模型时使用。打分不读它解出的图。
3. **障碍代价的输入是打分时刻的完整隐状态与这一步动作。** 完整隐状态 = 与 `dynamics.step` 里喂给各头相同的一段（当前实现为 `feature = [h ‖ z]`）。不接收深度图，不接收目标方向。贴上、擦得太近、还会再近，是它的不同程度。训练标签在离线用模拟器真值深度沿动作方向算距离，只在有真值时存在。沿该方向越近，标签越大。不用 ≤3 m 为 1、≥22 m 为 0 再乘 10 的那道崖。刻度由下面的排序锁住，不另定一个会盖过直飞的常数。空旷方向的代价保持低。
4. **真实一步和想象用同一个预测。** 真实奖励不再读罩的前向锥，也不再写入旧的二元碰撞分数。障碍代价在**动作执行前**打分：输入是 `(feature_t, action)`，其中 `feature_t` 是推进前的完整隐状态，不是 `dynamics.step` 之后的下一状态。采集器里先记下 `feature_t`、打分，再 `dynamics.step` 推进，再调用奖励。模拟器真值只负责制作标签和过门时标明哪条动作朝墙、哪条朝空。
5. **朝目标直飞是最大的正向项。** 输入是机体动作，以及机体坐标下的目标方向，没有深度图。位移沿目标方向大、横向和垂直分量小，这一步拿大权重。现有 `w_eff_heading` / `w_eff_strafe` 只有 0.08，压不过绕飞。`w_progress=1` 仍只记靠近了多少米，侧着靠近也会拿到；直飞权重再奖「正对目标飞过去」。前方没有障碍时，它高于同样靠近目标的侧飞、爬升、悬停和往空处退。正前方变近时，障碍代价高于这份直飞权重，绕开的一步可以赢。系数先用障碍代价的两个常数（前方空 = 0，前方很近 = 高）定下来，再让学出来的代价去对准这把尺子。
6. **想象里的目标方向要跟着偏航转。** 现在 `advance_goal_rel_body` 只减去机体位移，不按 `dyaw` 转动目标向量。转头之后，直飞仍按转之前的方向打分。这一步先改，直飞项才在多步想象里有效。
7. **另外三项失败代价。** 与直飞写在同一步里，真实环境与想象共用：
   - **不动。** 机体平移近于 0 且**不是**对准目标的偏航时扣分（悬停、原地乱转）。现有 `w_eff_idle=0.03` 只在沿目标方向前进不足 5 cm 时触发。新项看机体位移本身。直飞一步不触发。**对准目标的纯偏航**（小平移或零平移、`dyaw` 明显减小机体坐标下的航向误差）豁免不动罚，否则街巷「先转头再直飞」学不出来。单测：该过渡步低于直飞，但高于悬停、高于远离目标。
   - **远离目标。** 这一步让离目标更远，就在进度变负之外再扣一笔。朝目标直飞的一步不扣。空旷方向的障碍代价低；往空处退被选掉，是因为没有直飞分，再加上远离目标。
   - **一直平飞。** 连续多步高度和航向几乎不变，同时离目标的距离没有下降。朝目标直飞的水平一步不扣。
   规划器不新增几何打分。
8. **过门在代价训练之后、策略训练之前。** 同一帧 RGB 编进隐状态，奖励用已经定下的直飞系数。必过三组：前方空时直飞最高；前方近时朝墙直飞低于更空的靠近；左侧近、前方空时往前高于往左。不过门就不训策略。
9. **门过后再训策略（仅 125）。** 采集：`--no-planner`（yaml 里 `planner.enable: true`，否则仍会建规划器）且 **`--no-shield`**。想象 batch 16、H=15。部署验收用已有 `--planner-rollout closed_loop`、手写偏置关；**同一权重至少报罩关与罩开各一组**（n≥3 种子）。闭环步频和 504 token 成本本轮不改。

## 不做

- 不继续调 v5 之后的 escape / stuck / 近目标开关。
- 不把方向楔写进 `ImaginationPlanner`，也不写进想象打分的前向。楔只在离线标签和过门分组时使用。
- 不把深度图当作障碍代价的输入。
- 不保留旧的二元碰撞输出，也不新做一个只回答「撞 / 不撞」的头。
- 不新做一个「撞则否决」的门来代替回报排序。
- 不把朝目标直飞和「一直平飞」算成同一项。直飞是沿目标方向的大权重；一直平飞只扣距离不降的那段。
- 不让直飞权重盖过正前方已经很近的障碍代价。
- 不把空旷方向训成高障碍代价。
- 不在本轮重训盾的 DA3。
- 不把开阔地到达混进这轮训练。
- 不把本轮作业拆到 84 或双卡；在线采集与验收只在 125。
- 不在策略训练采集里开罩（部署再开）。

### 任务 5：过门（未过则不训策略）

同一帧 RGB 编进隐状态，奖励用任务 3 的系数和任务 4 的预测：
