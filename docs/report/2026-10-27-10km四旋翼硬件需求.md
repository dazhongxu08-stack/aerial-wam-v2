# 10 km 四旋翼硬件需求

**整理日期**：2026-10-27  
**范围**：飞机机体、动力、电池、数传，以及装在任务载荷里的机载计算机。  
**验收**：静风作业半径 10 km，巡航空速 16 m/s。飞到作业点停留约 10 分钟后返回，落地时剩余可飞时间不少于 15 分钟。全程约 46 分钟。

任务载荷 0.5 kg，内含机载计算机，由飞机持续供电 25 W。

---

## 1. 需求

| 项 | 需求 |
| --- | --- |
| 构型 | 四旋翼 |
| 桨 | 18 英寸双叶，桨距按空速 16 m/s |
| 轴距 | 0.72 m |
| 桨尖对角 | 1.2 m |
| 机身（不含桨） | 约 0.8 m × 0.6 m × 0.4 m |
| 停地高度 | 约 0.35 m |
| 起飞重量 | 11 kg |
| 空机 | 5.2 kg |
| 任务载荷 | 0.5 kg |
| 电池 | 1150 Wh，约 5.0 kg |
| 悬停功率 | ≤ 1.5 kW |
| 巡航 | 空速 16 m/s，相对地面高度 100 m |
| 最大平飞速度 | ≥ 20 m/s |
| 最大上升 / 下降速度 | ≥ 5 m/s / ≥ 4 m/s |
| 最大偏航角速度 | ≥ 90°/s |
| 贴目标速度 | 可稳定保持 5 m/s |
| 抗风 | 持续风 8 m/s 时仍能从 10 km 处返回 |
| 悬停精度 | GNSS：水平 ±1.5 m，垂直 ±0.5 m |
| 定位 | GPS、北斗 |
| 数传 | 作业空域内覆盖 10 km；断链后按航线返航 |
| 机载计算机 | Jetson Orin NX 16 GB，或算力不低于这一档 |
| 功耗档 | 25 W |
| 标称算力 | 100 TOPS（INT8） |
| 内存 | 16 GB LPDDR5，带宽 102.4 GB/s |
| 计算机装机重量 | 核心板、载板和散热合计 ≤ 250 g，含在 0.5 kg 载荷内 |
| 计算机供电 | 飞机母线，持续 25 W |
| 计算机接口 | USB、串口 |

## 2. 成品对照

下表为官网公开规格。航时都是飞到电量 0% 的实验室数，不是本文件第 1 节的验收口径。

| 机身（不含桨） | 810×670×430 mm | 980×760×480 mm |

| 带电池重量 | 约 6.5 kg | 约 9.7 kg |
| 最大载荷 | 2.7 kg | 6 kg |

| 最大平飞速度 | 23 m/s | 25 m/s |

| 偏航角速度 | 100°/s | 100°/s |

| 机载计算机 | 无此档算力 | 无此档算力 |

350 的尺寸接近第 1 节，公开电池能量约 526 Wh，低于 1150 Wh。400 的电池是 977 Wh，桨和轴距更大。两款都没有 Orin NX 16 GB 这一档机载算力，计算机要另装，重量和 25 W 供电算进任务载荷。
