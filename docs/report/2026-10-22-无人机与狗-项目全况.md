# Aerial WAM v2：无人机与机器狗 — 项目全况

**整理日期**：2026-10-22  
**仓库**：`aerial-wam-v2`  
**覆盖范围**：空中仿真主航道、后果模型、Tello / Orin 真机、Lumos 机器狗仿真与真机、近期现场测试

本文把 8 月建仓到 10 月下旬的主线收成一份可读的现状说明。数字以已有验收文档和 10 月 20–21 日真机材料为准；未过门的主张单独标出。

## 0. 一句话现状

| 平台 | 仿真 | 真机 | 当前主栈 |
|------|------|------|----------|
| **无人机（长航）** | Phase-2 到达 **86.7%（13/15）**，已验收 | Orin + Pixhawk 链路通；论文级试飞计数未满 | WAM（RSSM + 想象规划 + 三区罩） |
| **无人机（近障 / Tello）** | 后果模型（动作序列 → 碰撞 / 净空 / 目标进展）已训 | DA3 米制深度可用；关罩自动采与找红凳在飞 | 后果模型 + DA3；反应式策略兜底 |
| **机器狗（Lumos）** | 同一后果模型，`dog_ft` 在狗动力学上微调 | 仓库走向 12 m 目标进过 1 m 到达圈（里程计） | 后果模型只出 `dx`/`dyaw` → `(vx, vyaw)` |

两条载体共用「看当前深度 → 给候选动作打分 → 只走第一步」的后果模型思路；差别在权重、动作维和机体。空中长航仍以世界模型主栈报主成绩；近障与狗以后果模型为主。

## 1. 项目目标与技术路线

面向**纯视觉自主导航**：外感知主要是单目 RGB，结合 IMU / 高度（或狗的本体速度），做「感知—预测—决策—安全」闭环。

```text
任务：给一个目的地（坐标 / 方位 / 语义目标）
回报：自己飞过去或走过去，途中主动避障

仿真验证 → 模型训练 → 真机部署 → 真机数据反哺
```

历史上有两条可并存的决策栈：

1. **世界模型栈（WAM）**：DreamerV3 式 RSSM + 想象规划 + Actor-Critic + 三区安全罩。主成绩在户外城市长航线上。  
2. **后果模型栈（Consequence）**：BADGR / ProbColl 式「当前深度 + 目标 + 动作序列 → 碰撞与进展」；部署时对候选动作族打分，只执行第一步。主用于近障、Tello、机器狗。

二者不互相替代：长航主表仍引用 WAM；狗与室内近障当前交付物是后果模型。

## 2. 架构（两栈对照）

### 2.1 世界模型栈（空中长航）

```text
RGB 224×224 ──► RSSM 编码 ──► z_t (1536-D)
                 │
                 ├──► DA3 深度头（DINOv2-ViT-L + DPT）
                 ├──► 想象规划（短地平线打分）+ π
                 └──► 三区安全罩（深度 / τ / p_coll）
```

在线部署量级约 **0.35B–0.43B** 参数（WM + π + DA3）。Wan2.2 像素 DiT 只作离线预训练 / 蒸馏教师，闭环不加载。

### 2.2 后果模型栈（近障 / Tello / 狗）

10 月 21 日架构页口径：

```text
RGB ──► DA3 深度（s8j 微调头）──► 56×56 块最小 + 对数
      + 机体目标（方位、距离、高度差）+ 上一步动作
              │
              ▼
      后果模型（H=10，隐层 256；三种子平均）
              │
              ▼
      生存过线里进展最大的候选 → 只执行第一步
```

输出：碰撞风险、前/左/右净空、到目标的距离变化。规划规则（无人机冻结配方 f35）：生存 ≥ 0.95、视场约 35°、每步重规划；附加近终点短步、刹车、无候选朝空处转。

| | 无人机 | 机器狗 |
|--|--------|--------|
| 权重 | 生存：`krs6` ×3；靠近：`env_bh` ×3（另吃场景向量） | 从 `krs6` 微调的 `dog_ft`（**不用**场景向量） |
| 动作 | `dx, dy, dz, dyaw`（米 / 弧度每步） | 只用 `dx, dyaw`；`dy`/`dz` 丢掉 |
| 映射 | AirSim 多旋翼，评测约 5 Hz | `dx→vx` 0–0.35 m/s，`dyaw→vyaw` ±0.5 rad/s |
| 动力学 | 仿真多旋翼 | 延迟、死区、增益、一阶滞后（按真狗桥标定） |
| 挑选 | 生存 ≥ 0.95 | 仿真对比常用生存 ≥ 0.75 |

**不能接错**：仿真狗机体仍是多旋翼相机高度约 0.6 m、2 Hz 的狗设置；Orin 上 0.06 m 缩放与训练模型单位不是同一套；`env_bh` 的场景向量不能接进 `dog_ft`。

### 2.3 近期补上的「场景物体」能力（代码已合进仓库，权重待训）

后果模型原先只吃深度，矮凳子在巡航高度下容易读成「前方空旷」。现已具备：

- **识别层**：例如红色凳子（HSV + 连续帧确认），写出禁区扇区；  
- **深度注入**：把物体写成全高虚拟柱子，供反应式策略与旧后果权重使用；  
- **模型内语义头（进行中）**：掩码通道 + 禁区 logit，用仿真轨迹合成标签训练，无需仿真里真有红凳。

真机找凳脚本：`tello_find_object.py`（YOLO-World TorchScript + 颜色过滤 + `TelloConsequencePolicy`）。

## 4. 无人机真机

### 4.1 平台与链路

| 平台 | 组成 | 状态 |
|------|------|------|
| **正式机** | Orin 伴飞 + Pixhawk 6C + SJCAM + H12 | 9 月 14 日软硬件一体接通；手控/自主切换、录制可用 |
| **Tello 小机** | Tello 热点 → Orin USB 网卡 → Mac 地面站 / H12 | 室内近障与后果后训练主试验台；默认地面锁 `ALLOW_FLY=0` |

动作统一为机体系前进 / 侧移 / 升降 / 偏航；Tello 经 `rc` 发出。

### 4.2 DA3 真机尺度（2026-10-13）

室内卷尺标定：

| 真值 | DA 中心中位 | 结论 |
|------|-------------|------|
| 1.0 m | **1.02 m** | 可贴 |
| 2.0 m | **1.97 / 2.02 m** | 可贴 |
| ≈2.8 m | 2.49–2.57 m | 略近约 10%，远近顺序对 |

**用途**：后果模型深度输入、关罩近障停/转。不要全局再乘倍率；桌椅进框时不要用 fwd-min 当墙距；`dgoal` 不要用 Tello 积分 xy。

### 4.3 后果后训练采集

标准：`docs/research/oa-no-teacher/tello-consequence-collect.md`。

- 需要：深度（可事后 DA3）、目标、真实发出的 `rc`、近障 / 碰撞标签、有效空中 60–120 s、高度 0.8–1.5 m。  
- **禁止**：固定时间轴打杆的「示教程序」（10-12 那批已否决）。  
- 2026-10-15 户外桶/墙一批：6 条到 **域差可用**，全无轻碰，**不到后训练可用**（缺室内场景 + 至少 2 条轻碰）。

## 8. 缺口与下一步（按优先级）

### 已证明、可以对外说

1. 户外纯视觉长航仿真 **86.7%**，规划必要，关罩仍有六成多。  
2. 单目深度在 Tello 室内 1–2 m 可贴卷尺。  
3. 同一后果模型配方可迁到狗动作空间，并在仓库积分意义下进过到达圈。  
4. 真机链路（正式机 + Tello + Lumos/H12）均可录第一视角与路径。

### 尚未过门 / 需诚实标注

1. **论文 E5**：Orin 正式机不少于 10 次短航到达计数未完成。  
2. **后果后训练**：尚缺合格室内近障 + 轻碰批次；10-15 户外批不能直接微调。  
3. **找红凳**：检测与策略在飞，10-21 演示趟未锁定。  
4. **狗到达**：仅有里程计 / 指令积分，无卷尺；贴障 0.63 m 未停需进安全策略。  
5. **`dog_ft` 上真狗**：架构页仍写未作为正式真狗部署；仿真狗机体 ≠ 真狗 URDF 进 AirVLN。  
6. **语义进后果模型**：代码与合成训练管线已备，正式权重需在 GPU 上对现有数据集跑 `--sem-keepout`。  
7. **深度尺度**：长航上「自估距离」相对真距离仍差一大截（E3），是继续抬到达率的主瓶颈之一。

### 建议近期动作

| # | 动作 | 目的 |
|---|------|------|
| 1 | 室内布置障碍，按后训练标准采满 6–10 条（含 ≥2 轻碰） | 后果模型真机微调 |
| 2 | 找凳：加固锁定（检测 + 确认帧 + 丢失策略），再飞演示趟 | 补上 10-21 未锁定 |
| 3 | 狗：卷尺复核一条 12 m 到达；贴障减速 / 停 | 把「积分到达」升成可引用到达 |
| 4 | 训语义后果权重并回挂 Tello `--avoid` / 找物链路 | 场景物体进模型而不只改深度图 |
| 5 | 正式机补 E5 计数（短航 ≤5 m） | 论文真机行 |

## 9. 结论

项目已从「仿真世界模型能飞长航」走到「真机多载体可飞、可录、可测」。空中长航的对外主数字仍是 **86.7%**；近障与跨平台（Tello / Lumos）的工程主线是 **后果模型 + DA3**。10 月 21 日现场证明了两条：小飞机能在 1 m 高度飞满三分钟并做近障间隙；机器狗能在仓库里按同一类规划走进目标邻域——但找物锁定、后训练数据、狗的米制到达与贴障安全都还没有收成验收级结论。

下一阶段的关键不是再扩一条新架构，而是把**已有后果模型**用合格真机数据钉牢，并把「认出场景物体并绕开」从外挂规则收进模型权重。
