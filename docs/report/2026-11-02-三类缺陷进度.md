## 仿真和飞机不是同一套用法

不足同源：都是当前帧 56×56 深度上的 krs6 生存头，只看像素层，不进 DA3 隐空间。

| | 仿真主航道 | Tello 真机 |
|---|---|---|
| 生存 | krs6 ×3，阈 0.95 | 同一组冻结 krs6，当盾 |
| 进度 | `env_bh`，过线后挑更近 | **不用**（没有米制 xy，不用 vg 积分当 `dgoal`） |
| 动作 | 大候选库，执行第一步再重来 | 只有悬停 / 原地转 / 小幅前进；禁止后退、侧飞、前进+偏航 |
| 朝哪走 | 进度头 | 反应层净空 + 起飞相对方位 |

飞机上选杆被收成生存判断，不是模型只会二分类。`dgoal` 和三锥仍在网络里，Tello 挑家族时不用。正对墙、室内 1–3 m、DA3 大致准时，经常能停或改成原地转；侧向近障、转角盲区、动态物，没有保证。

## 论文基础

主干是 BADGR / ProbColl / ORACLE 那条「画面 + 候选动作 → 碰撞后果 → 滚动选第一步」，不是 RSSM 世界模型，也不是端到端飞控。单目深度当条件来自 MonoMPC。现在飞的 krs6 生存盾，是这条结构在 Tello 上砍掉进度段之后剩下的第一段。

出处：`docs/research/oa-no-teacher/reading-consequence/`。前 4 篇是骨架，5–7 是辅助和已知缺口，8–9 只碰训练/部署要不要挂罩。逐条对照在同目录 `后果模型设计依据-论文摘录.md`。

| 现在在用的 | 主要出处 | 要对齐的说法 |
|---|---|---|
| 随机/自飞采集，事后用碰撞标，不靠专家 | BADGR、ORACLE | 直接支持 |
| 深度图卷积成初态，循环网逐步读入候选动作 | BADGR 框架；拼接目标/上一步更像 ORACLE | 不是和 BADGR 一一对应 |
| \(P(\text{撞}\mid\text{画面}, \text{动作序列})\) | ProbColl | 直接支持。他们是小 MLP + 16×16 灰度，我们是 CNN+GRU + 56 深度 |
| 逐步 hazard，连乘成 10 步生存 | ORACLE 逐步碰撞；Collision Replay 的 hitting-time | 部分支持。ORACLE 用衰减求和当代价，不是生存连乘；Collision Replay 没拿来做控制 |
| 固定基元库，打分，执行第一步再规划 | ORACLE、ProbColl；BADGR 是连续采样不是固定库 | 直接支持「滚动」；库的形态跟 ORACLE |
| 先滤风险，再在安全集合里靠近目标 | ORACLE 两段式；并批评 BADGR 把目标和避碰揉成一个奖励 | 我们用绝对阈 0.95 + 学到的 `dgoal`；ORACLE 用相对阈 + 几何航向 |
| 预测深度当条件，不当障碍地图 | MonoMPC | 直接支持 |
| 前/左/右净空当稠密辅助，选动作不用 | Future Depth 支持稠密未来深度 | 主用碰撞、净空只辅助，和 MonoMPC / Future Depth 的主建议是反的 |
| 三种子平均 | ProbColl 集成的外形 | 他们用 bootstrap + 均值+λ×标准差；我们同一数据换种子、λ=0 |
| 只看当前帧 | 论文当缺陷写 | MAVRL：加记忆隐状态成功率 0.50→0.71；SIGN 也有转头侧碰 |
| 训练不挂罩 | NavRL 部署再加盾 | 「主结果报关罩」不能引这两篇，是项目自己的口径 |
| 动作限制在视场内 | ORACLE 基元不出深度 FOV | 直接支持 |

不是论文来的：同一状态把每种候选都在仿真里飞一遍（分支采样）、10 步、0.95、网络宽度、高度门、Tello 四家族。

## 大结构：骨架不动，还空着的层

骨架可以不动：像素深度 → 动作条件后果 → 先安全后进度（飞机上只有安全）。换隐空间世界模型、把安全和进度加成一个数、用 vg 积分顶 `dgoal`，都是换路线。第一类、第二类是同一骨架上的标定，不是换骨架。

还能动、而且论文或自己实验已经指着缺口的：

1. **决策量（结构内，未用满）**  
   头已经出 hazard、三锥、`dgoal`，Tello 只用末端生存。可试：侧向近时用锥或「这一步会扫到的几何」否决直行，不降全局 0.95。第一类、第二类仍是把生存头标定到真命令。
2. **不确定度**  
   ProbColl 的核心（均值 + λ×标准差）没借。三种子只平均，侧向 0.97–0.98 仍放行。加 λ 或成员不一致就悬停，不必改网络。
3. **记忆（最大的结构洞）**  
   MAVRL 明确说当前帧不够。近处盲区和飞远不是一层。像素堆叠、1 m 硬清障已经否了。还没做成的是机体坐标周围图只进生存初态；MAVRL 那种用隐状态重建 T 步前深度会动编码器，等于新权重，不能当 krs6 的小补丁。
4. **规划差（仿真 vs 飞机）**  
   ORACLE 的安全集合永远不空（相对阈）；我们绝对 0.95 会全灭再走「最安全/悬停」。Tello 候选只有 4 条。飞机上进度段关掉是缺 xy；真机要「先安全后进度」，得先有不靠 vg 的距离，否则大结构在飞机上永远是盾而不是规划器。
5. **动态**  
   NavRL 靠体素里清检测框 + 部署盾。当前 10 步假设世界静止。加动态是新输入，不是把 krs6 再训一轮。

不要当「优化大结构」的：再降 0.95、把第一类 24 个位置再标进第二类、恢复 `--seen-clear-m`、为盾去训 RSSM。
