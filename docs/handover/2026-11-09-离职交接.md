## 1. 项目与当前阶段

纯视觉空中导航。外感知是一颗单目 RGB，飞控已有的 IMU 与高度一并使用。路线是仿真验证 → 模型训练 → 真机部署。

在线闭环：

```text
RGB 224×224 + proprio → RSSM 潜变量 z（1536 维）
    → DA3 深度 D̂、光流碰撞时间 τ、想象规划 + 策略 π
    → 三区安全罩（D̂、τ、p_coll 任一超阈则保守动作）
```

Wan2.2 像素模型只在 H100 上做离线预训练和蒸馏，闭环不加载。在线权重大约 0.43B（含训练用 RGB 解码器），推理活跃大约 0.35B。动作是机体系 `(dx, dy, dz, dyaw)`，约 5 Hz。到达判据是距目标 ≤ 3 m。

**当前阶段**：Phase-2 户外长航已关闭。Phase-3 在做户外长航与室内精飞的统一模型。真机软硬件已接通，实地自主试飞还没做。视觉目标跟踪（vgoal）在旁线仓并行，不并进 Phase-3。
