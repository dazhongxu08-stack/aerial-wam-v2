# 接口

基址：`http://<host>:8100`  
入口：`rt-api`  
默认不运动。地面/空中任务必须 `arm=true`。

## 命令行

```bash
rt-api parse '<自然语言指令>'
rt-api health
rt-api serve --host 0.0.0.0 --port 8100
```

## HTTP

| 方法 | 路径 | 输入 | 输出 |
|------|------|------|------|
| GET | `/v1/health` | — | `{ok, ground, air, link}` |
| GET | `/v1/openapi.json` | — | 契约 |
| POST | `/v1/parse` | `{"text":"..."}` | ParseOut |
| POST | `/v1/ground/tasks` | `{"text":"...","arm":true}` | 无 `arm` 拒绝 |
| GET | `/v1/ground/task` | — | 当前地面任务 |
| POST | `/v1/ground/abort` | — | 中止地面任务 |
| GET | `/v1/air/status` | — | `{ok, airborne, battery, height_cm, frame_age_s, allow}` |
| POST | `/v1/air/tasks` | `{"text","range_m","bearing_deg","arm":true}` | 无 `arm` 不起飞 |
| GET | `/v1/link/status` | — | 链路状态 |
| POST | `/v1/link/cmd` | 指令 JSON | 链路回执 |

`health` 中 `ground` / `air` / `link` 取值：`idle`、`busy`、`offline`、`down`、`up`。

## ParseOut

| 字段 | 含义 |
|------|------|
| `text` | 原指令 |
| `object` | 目标物体 |
| `prompts` | 检测短语 |
| `color` | 颜色，可空 |
| `range_m` | 距离（米） |
| `range_tol_m` | 距离容差 |
| `bearing_rad` | 机体方位，右为正 |
| `heading_rad` | 世界航向，可空 |
| `notify` | `ground` / `air` |

## 示例

```json
POST /v1/parse
{"text": "正前方10米找一个红色的凳子"}
```

```json
{
  "text": "正前方10米找一个红色的凳子",
  "object": "stool",
  "prompts": ["stool", "bench", "chair"],
  "color": "red",
  "range_m": 10.0,
  "range_tol_m": 15.0,
  "bearing_rad": 0.0,
  "heading_rad": null,
  "notify": ["ground"]
}
```

```json
POST /v1/ground/tasks
{"text": "正前方10米找一个红色的凳子", "arm": true}
```

```json
POST /v1/air/tasks
{"text": "对面墙", "range_m": 4, "bearing_deg": 0, "arm": true, "air_s": 75}
```
