# 部署

安装目录：`/opt/aerial_orin`  
对外进程：`rt-api`，端口 `8100`  
默认不运动，任务需 `arm=true`。接口见 [接口.md](接口.md)。

## 环境

- NVIDIA Jetson（JetPack，Python 3.10，可用 GPU 的 PyTorch）
- 将产品目录放到 `/opt/aerial_orin`

## 启动

```bash
/opt/aerial_orin/bin/rt-api serve --host 0.0.0.0 --port 8100
```

```bash
/opt/aerial_orin/bin/rt-api health
/opt/aerial_orin/bin/rt-api parse '<自然语言指令>'
```

```bash
curl -s http://127.0.0.1:8100/v1/health
```

停止：对 `serve` 进程 Ctrl+C。
